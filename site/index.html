Screenshots in one keystroke.

Snapt is a fast, lightweight, open-source screenshot tool for Windows, macOS and Linux. Press PrtSc, select an area, draw an arrow or a caption, then copy or save it. No accounts, no cloud, a few megabytes on disk.

Everything you need, nothing you don't

If you have used LightShot, you already know how Snapt works. It just stays out of your way, and keeps your screenshots on your machine.

Instant

A native Rust binary that starts in a blink and sits idle in the tray until you press PrtSc.

Lightweight

No Electron, no web view, no runtime to install. A few megabytes on disk and almost no memory.

Private

No accounts, no telemetry, no uploads. Your shots never leave your computer.

Precise selection

Drag to select, then move or resize by the handles. Works on every monitor and on HiDPI screens.

Copy, save, print, search

Send the area to the clipboard, save it as PNG or JPEG, print it, or search the web for similar images.

Annotate

Pen, lines, arrows, boxes, marker and text right on the selection, in any color, with undo and redo.

How it works

No windows to click through.

Press PrtSc

Or Cmd+Shift+9 on macOS, or Take screenshot in the tray menu. The screen freezes.

Select an area

Drag with the mouse. Adjust it by the edges, or press Ctrl+A for the whole screen.

Draw on it

Pick a tool on the toolbar or press its letter, like A for an arrow or T for text.

Copy or save

Press Ctrl+C and paste anywhere, or Ctrl+S to save a file.

Questions

The short answers. Anything else, ask in Issues.

Windows or macOS warns me when I open Snapt

Snapt is not code-signed yet. On Windows, click More info, then Run anyway. On macOS, try to open it once, then go to System Settings → Privacy & Security and click Open Anyway. If macOS says the app is damaged, run xattr -dr com.apple.quarantine /Applications/Snapt.app in Terminal.

macOS asks for Screen Recording permission

That is how macOS lets apps see the screen. Allow Snapt in System Settings → Privacy & Security → Screen Recording, then restart it.

I don't see the tray icon on Linux

Snapt uses the StatusNotifierItem protocol. KDE supports it out of the box. On GNOME, install the AppIndicator extension.

Does Snapt upload my screenshots?

No. Snapt has no servers of its own and never sends your screenshots anywhere. The only thing it asks the internet is GitHub, once a day, whether a new version is out, and you can turn that off in the settings.

How do I change the shortcut or the save folder?

Open Settings in the tray menu (menu bar on macOS), or run snapt --settings. In the settings window you can switch the language, record a new shortcut, pick the folder and format (PNG or JPEG), save without asking, start Snapt with the system, and let it replace the system screenshot tool on PrtSc.

How does Snapt update?

It checks GitHub Releases once a day and offers Update in the tray. The Windows installer, the macOS app and the AppImage update themselves; for the .deb, the download page opens. You can turn the check off in the settings.

PrtSc does nothing on Wayland

Wayland doesn't let apps grab global shortcuts. Bind snapt --capture to a key in your desktop's keyboard settings, and it takes a screenshot with the running Snapt.

Is it really free?

Yes. Snapt is open source under the MIT license, with no ads, no paid tier and no tracking.
